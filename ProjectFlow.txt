# Fitness Quiz Application - Developer Documentation

## Project Overview
A React-based fitness quiz application with 33 questions spanning multiple categories, followed by a comprehensive promotions/offers page. Built with Vite, React Router, and Material-UI.

---

## Architecture

### Two Main Pages:
1. **Quiz Page** (`/`) - 33-question fitness assessment
2. **Promotions Page** (`/promotions`) - Full offers/marketing page
(fully responsive pages)

---

## Tech Stack
- **Framework**: React 19.2.0 + Vite 7.2.4
- **Routing**: React Router DOM 6.30.2
- **UI Library**: Material-UI (MUI) 5.18.0
- **Animations**: Framer Motion 12.23.25
- **Icons**: Iconify React 6.0.2
- **Charts**: Recharts 3.5.1
- **Date Handling**: date-fns 4.1.0, MUI Date Pickers 8.19.0
- **Carousel**: Swiper 12.0.3

## Quiz Flow & Data Management

### LocalStorage Strategy
**Key**: `quizStorage`

**Structure**:
```javascript
{
  currentIndex: 1,          // Current question (1-33)
  previousIndex: 0,         // Previous question index
  gender: "",               // User's selected gender ("male"/"female")
  answers: {                // Map of questionId -> answer
    1: "male",
    2: "lose_weight",
    // ... etc
  }
}
```

### Custom Hook: `useQuizStorage`
Located: `src/hooks/useQuizStorage.js`

**API**:
- `quiz` - Current quiz state object
- `updateQuiz(patch)` - Updates quiz state + syncs to localStorage
- `back()` - Navigate to previous question

**Key Features**:
- Initializes from localStorage on mount
- Auto-persists every state change
- Provides single source of truth for quiz data

## Question Types & Components

### 1. **gender-selection** → `GenderSelection.jsx`
   - Visual gender selection with images
   - Sets `quiz.gender` for conditional rendering later

### 2. **single-choice** → `SingleChoiceEmoji.jsx` OR `SingleChoiceImage.jsx`
   - Router decides based on `question.options[0]?.imgUrl`
   - Emoji version: Text labels with emoji prefixes
   - Image version: Visual cards with images

### 3. **multi-choice** → `MultipleChoiceEmoji.jsx` OR `MultipleChoiceImage.jsx`
   - Allows multiple selections
   - "None of the above" option clears other selections

### 4. **height-input** / **weight-input** → `MeasurementInput.jsx`
   - Toggle between units (FT/CM, LBS/KG)
   - Shows BMI calculation if `showBMI: true`

### 5. **text-input** → `TextInput.jsx`
   - Handles age, name, etc.
   - Validation rules in question data

### 6. **date-input** → `DateInput.jsx`
   - MUI DatePicker integration
   - Optional skip functionality

### 7. **info-page** → `InfoPage.jsx`
   - Informational screens with progress indicators
   - Auto-advances on continue

### 8. **summary-page** → `SummaryPage.jsx`
   - Shows user profile summary
   - Displays BMI if applicable

### 9. **prediction-page** → `PredictionPage.jsx`
   - Shows weight loss prediction graph
   - Calculates target date

### 10. **processing-page** → `ProcessingPage.jsx`
    - Loading screen with animations
    - Prepares transition to promotions

## Navigation Flow

### Quiz Progression:
1. User answers question
2. `handleContinue(questionId, answer)` called
3. Updates `quiz.answers` + increments `currentIndex`
4. When `currentIndex` reaches 33 → Navigate to `/promotions`

### Back Navigation:
- `handleBack()` decrements `currentIndex`
- Previous answers preserved in localStorage
- Can navigate back through entire quiz

## Key Implementation Details

### Lazy Loading:
```javascript
const QuizPage = React.lazy(() => import("../pages/QuizPage"));
```
- Both main pages lazy loaded via React.lazy
- `PageSkeletonLoader` shown during load

### Progress Bar:
- Linear progress: `(currentIndex / totalQuestions) * 100`
- Visual feedback on quiz completion

### Conditional Rendering:
- Question type determined by `question.type`
- `QuestionRouter` acts as switch/case for components
- Gender-specific images switched in components

### State Management:
- No global state library (Redux/Context)
- Single custom hook handles all quiz state
- Promotions page mostly stateless presentation

## Common Development Tasks

### Adding a New Question:
1. Add question object to `quizQuestions.js`
2. Import any images needed
3. Assign appropriate `type`
4. Create new component in `questionTypes/` if custom type needed
5. Update `QuestionRouter.jsx` switch case

### Adding New Promotion Section:
1. Create `Section15.jsx` in `components/promotion/`
2. Import and add to `Promotions.jsx`
3. Style with MUI `sx` prop

### Modifying Quiz Logic:
- Edit `useQuizStorage.js` for storage changes
- Edit `QuizPage.jsx` `handleContinue()` for flow changes

### Styling Changes:
- Global background: `QuizPage.jsx` `sx={{ backgroundColor: "#7061a2" }}`
- Card styles: `QuestionRouter.jsx` Card component
- Component-specific: Each component's `sx` prop

## Important Notes

1. **No API Calls**: All data stored client-side in localStorage
2. **No Authentication**: Public quiz, no user accounts
3. **Image Dependencies**: All question images must be in `assets/quizQuestion/`
4. **Responsive Design**: MUI breakpoints used throughout (`xs`, `sm`, `md`, `lg`)
5. **Browser Support**: Modern browsers (ES6+ required)
